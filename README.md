# 国外小博主寻找器 · 发布仓库

这个仓库只放**发布产物**和自动更新用的 `latest.json`；源码在主工程目录里，随每个版本打 `creator-finder-source-<版本>.zip` 上传。

- 版本：1.1.0
- 便携版：creator-finder-1.1.0-portable.zip（109.8 MB）
- 源码包：creator-finder-source-1.1.0.zip

## 国内下载

软件内「检查更新」会自动在直连和国内镜像之间测速；手动下载可以用：
